# de_toolkit namespace shim

This companion dbt package provides the short, globally available
`de_toolkit` macro namespace. Every public macro delegates to the canonical
`dbt_data_engineering_toolkit` package.

Install this published subdirectory together with the repository root at the
same pinned Git revision. Do not install the shim by itself: it intentionally
has no independent implementation or third-party dependencies. The wrappers
are generated by `scripts/generate_alias_facade.py`; do not edit them by hand.

The canonical root can be listed on dbt Package Hub. This nested project stays
a pinned Git `subdirectory` dependency unless it is mirrored into its own
top-level repository and registered as a second Hub package.

See the repository root README for installation and usage, and
`docs/deployment.md` for the exact publication choices.
