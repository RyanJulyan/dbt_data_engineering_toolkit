# dbt_data_engineering_toolkit V2.3.0

V2.3.0 is the first public release: a production-oriented dbt package and PyPI compiler with a
SQL-first API, governed Excel-to-ODCS workflow, enforced coverage, Fusion validation, and explicit
multi-warehouse support.

## Release guarantees

- Python statement coverage is 85.01%; CI and release automation fail below 80%.
- dbt DuckDB-scoped macro implementation coverage is 98.53% (134/136), and public-API direct
  execution coverage is 100% (104/104); CI fails below 80% and rejects undocumented facades.
- dbt Core support covers BigQuery, Snowflake, DuckDB, Databricks, Redshift, Athena, ClickHouse,
  and Spark with isolated adapter parse/dispatch gates and credentialed build workflows.
- The root project declares `require-dbt-version: [">=1.10.6", "<3.0.0"]`, passes a full Fusion
  DuckDB build in CI, uses evaluator-safe Fusion flags, and provides credentialed Fusion workflows
  for every requested warehouse currently supported by Fusion.
- Athena and ClickHouse are explicitly Core-only until dbt Fusion provides those adapters.

## Included

- Inline cleaning, mapping, conversion, formatting, validation, assertion, quarantine, audit,
  relation, statistical, string, and feature-transformation macros.
- Canonical `dbt_data_engineering_toolkit.*` calls plus a generated `de_toolkit.*` companion
  namespace with signature-drift protection.
- Stable facades over dbt-utils and dbt-assertions, with codegen and dbt-project-evaluator kept as
  implementation dependencies.
- A production-safe guided workbook builder with no sample rows by default.
- Direct import of ODCS YAML, official ODCS Excel through Data Contract CLI, SQL DDL, and dbt
  manifests.
- One authoritative visible ODCS `Quality` sheet plus separate `Operational Validation` and
  `Operational Parameters` sheets.
- Typed workbook interpretation, stable diagnostics, deterministic atomic generation, Data
  Contract synchronization, SQLFluff configuration, drift protection, and isolated proof runs.
- Deterministic short names for synchronized contract tests and a release-gated Windows-safe
  source archive that is CRC-checked and fully extracted before publication.
